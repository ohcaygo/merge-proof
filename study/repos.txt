# Candidate repositories for the merge-proof G1 corpus.
#
# Selection criterion, fixed BEFORE any result was observed: public
# repositories that are known or expected to merge pull requests authored by
# AI coding agents, so that a corpus of agent-authored merges can be built at
# all. This is a purposive sample of repositories that use coding agents. It
# is NOT a random sample of GitHub, and rates measured on it should not be
# read as rates for GitHub as a whole.
#
# Repositories that fail to clone or analyze within the collection budget are
# reported as excluded in study-data.json rather than silently dropped.
#
# Stratification is NOT assigned here. It is computed from git after
# collection, from the number of distinct commit authors in each repository.
